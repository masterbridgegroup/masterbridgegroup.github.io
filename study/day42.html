2026-08-14 · 2과목 1주차 복습 + 종합 테스트 15문제 (약 1시간)

복습 한 스푼 🥄

어제(Day 41)는 O(n log n)급 고급 정렬 3형제를 배웠어요. 딱 하나만 다시: 퀵 정렬은 평균 O(n log n)이지만 최악(이미 정렬된 자료)에는 O(n²)로 느려지고, 합병 정렬은 언제나 O(n log n)으로 안정적이었죠. 오늘은 이번 주(Day 36~41) 내용을 표로 정리하고 종합 테스트 15문제로 마무리합니다.

1. 자료구조 전체 지도

자료구조(데이터를 담는 그릇의 모양)는 크게 두 갈래로 나뉘어요.

분류종류한 줄 특징
선형 구조
(한 줄로 늘어섬)		배열 · 연결 리스트배열=번호로 바로 찾기 빠름 / 리스트=끼우고 빼기 빠름
스택 · 큐 · 데크넣고 빼는 순서를 규칙으로 정한 그릇
비선형 구조
(갈라짐)		트리부모-자식 계층 구조, 사이클(고리) 없음
그래프점(정점)과 선(간선)의 자유로운 관계망, 사이클 가능
시험 포인트 — "선형 구조가 아닌 것은?" → 트리, 그래프. 반대로 "비선형 구조는?" → 트리, 그래프. 이 분류만으로 한 문제 맞힐 수 있어요.

2. 스택·큐·데크 다시 보기

구조규칙입출구대표 활용
스택(Stack)LIFO(후입선출) — 나중에 넣은 게 먼저 나옴한쪽(top)만되돌리기, 함수 호출 기록, 재귀, 수식 변환
큐(Queue)FIFO(선입선출) — 먼저 넣은 게 먼저 나옴양쪽(rear 입력, front 출력)프린터 대기열, 작업 스케줄링, BFS
데크(Deque)양쪽 모두 넣고 뺄 수 있음양쪽 다스택과 큐의 역할을 동시에 해야 할 때
암기 팁 — 스택은 접시 쌓기(맨 위 접시부터 꺼냄), 큐는 은행 줄서기(먼저 온 사람 먼저). 이 그림만 기억하면 헷갈리지 않아요.
시험 포인트 — 원형 큐는 배열의 끝과 처음을 이어 붙여 빈 공간 낭비를 없앤 큐. "선형 큐의 단점을 해결"이라는 표현이 나오면 원형 큐입니다.

3. 트리 순회와 그래프 공식

트리 순회(나무의 모든 노드를 한 번씩 방문하는 순서)는 루트(뿌리)를 언제 방문하는가로 이름이 정해져요.

순회방문 순서수식 표기
전위(Preorder)루트 → 왼쪽 → 오른쪽전위 표기 (+ A B)
중위(Inorder)왼쪽 → 루트 → 오른쪽중위 표기 (A + B)
후위(Postorder)왼쪽 → 오른쪽 → 루트후위 표기 (A B +)

그래프에서 꼭 외울 공식 2개입니다.

정점이 n개일 때 최대 간선 수 — 무방향 그래프는 n(n-1)/2, 방향 그래프는 n(n-1). 방향이 있으면 왕복 2개로 세니까 딱 2배!
시험 포인트 — 트리에서 노드가 n개면 간선(가지)은 항상 n-1개입니다. 그리고 신장 트리(Spanning Tree)는 모든 정점을 사이클 없이 연결한 트리, 그중 가중치 합이 가장 작은 것이 MST(최소 신장 트리)예요.

4. 정렬 알고리즘 성적표 총정리

정렬평균최악핵심 한 줄
버블O(n²)O(n²)옆 사람과 비교·교환, 1회전이면 최댓값이 맨 뒤 확정
선택O(n²)O(n²)최솟값을 찾아 맨 앞으로, 교환 횟수가 적음
삽입O(n²)O(n²)카드 정리하듯 알맞은 자리에 끼워 넣기, 거의 정렬된 자료에 유리
퀵O(n log n)O(n²)피벗(기준값)으로 편 가르기, 평균 속도 최강
합병O(n log n)O(n log n)반씩 쪼갰다 합치기, 언제나 일정하지만 추가 메모리 필요
힙O(n log n)O(n log n)힙(최댓값이 뿌리에 오는 트리)에서 하나씩 뽑아내기
시험 포인트 — 시험에 가장 많이 나오는 두 가지. ① 퀵 정렬의 최악은 O(n²) ② 합병·힙은 최악도 O(n log n). 그리고 빅오 크기 순서는 O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)입니다.
