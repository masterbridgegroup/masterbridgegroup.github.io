트리 — 거꾸로 자라는 나무

2026-08-10 · 오늘 배울 개념 5개 + 퀴즈 10문제 (약 1시간)

복습 한 스푼 🥄

어제(Day 37)는 스택과 큐를 배웠어요. 딱 하나만 다시: 스택은 LIFO(나중 것 먼저), 큐는 FIFO(먼저 온 것 먼저)! 접시 쌓기와 은행 줄서기였죠. 오늘은 드디어 비선형 구조의 대표, 트리를 만납니다.

1. 트리(Tree)란? — 가지를 치는 비선형 구조

트리는 데이터(노드)들이 부모-자식 관계로 가지를 치며 연결된 비선형 구조예요. 나무를 거꾸로 세운 모양이라 맨 위가 뿌리(루트)입니다.

비유 — 회사 조직도! 사장(루트) 아래 부서장, 그 아래 팀원... 컴퓨터의 폴더 구조도 트리예요. 중요한 규칙: 사이클(빙 돌아 제자리로 오는 길)이 없다는 것!
용어뜻
루트(root)맨 위의 시작 노드 (사장님)
단말 노드(leaf, 리프)자식이 하나도 없는 끝 노드 (잎사귀)
차수(degree)한 노드가 가진 자식의 수
트리의 차수노드 차수 중 가장 큰 값
깊이(depth)/레벨루트에서 몇 층 내려왔는지
시험 포인트 — 그림을 주고 "트리의 차수는?", "단말 노드의 수는?"을 묻는 계산 문제가 매년 나와요. 차수 = 자식 수, 단말 = 자식 없는 노드만 세면 됩니다.

2. 이진 트리 — 자식이 최대 2명

이진 트리(binary tree)는 모든 노드의 자식이 최대 2개(왼쪽·오른쪽)인 트리예요. 컴퓨터가 다루기 쉬워 가장 널리 쓰입니다.

종류모양
포화 이진 트리모든 층이 빈틈없이 꽉 참 (완벽한 피라미드)
완전 이진 트리마지막 층만 왼쪽부터 차례로 채워짐 (공연장 좌석을 앞줄부터, 왼쪽부터 채운 모양)
편향 트리한쪽으로만 자식이 이어짐 (사실상 한 줄, 지팡이 모양)
시험 포인트 — 이진 트리에서 레벨 k(루트가 레벨 1)의 최대 노드 수는 2ᵏ⁻¹개예요. 레벨 3이면 최대 4개! 이 공식이 자주 출제됩니다.

3. 트리 순회 ① — 전위·중위·후위가 뭐길래

순회(traversal)는 트리의 모든 노드를 빠짐없이 한 번씩 방문하는 순서 규칙이에요. 부모(Root)를 언제 방문하느냐로 이름이 정해집니다.

순회순서기억법
전위(Preorder)Root → 왼쪽 → 오른쪽부모 먼저 (전 = 앞)
중위(Inorder)왼쪽 → Root → 오른쪽부모 가운데 (중 = 중간)
후위(Postorder)왼쪽 → 오른쪽 → Root부모 나중 (후 = 뒤)
비유 — 부모님과 두 아이가 식당에 갔을 때 누가 먼저 주문하나: 전위는 부모 먼저, 중위는 첫째-부모-둘째, 후위는 아이들 먼저 부모 마지막. Root의 위치만 기억하면 끝!

4. 트리 순회 ② — 직접 해보기

루트가 A, A의 왼쪽 자식이 B, 오른쪽 자식이 C이고, B 밑에 D와 E가 있는 트리로 연습해 볼게요.

순회과정결과
전위A 방문 → B 서브트리(B→D→E) → CA B D E C
중위B 서브트리(D→B→E) → A → CD B E A C
후위B 서브트리(D→E→B) → C → AD E B C A
시험 포인트 — 순회 문제는 그림만 주면 무조건 풀 수 있는 점수 문제예요. 왼쪽 서브트리(부분 나무) 전체를 하나의 덩어리로 보고 재귀적으로(같은 규칙을 반복해서) 적용하는 게 요령입니다.

5. 수식 표기법 — 순회로 수식 바꾸기

연산자(+, × 같은 기호)를 어디에 쓰느냐에 따라 수식 표기법이 세 가지예요. 사실 트리 순회와 같은 원리입니다.

표기법예 (A+B)대응 순회
전위 표기(Prefix)+AB전위 순회
중위 표기(Infix)A+B (우리가 평소 쓰는 것)중위 순회
후위 표기(Postfix)AB+후위 순회
변환 요령 — A+B×C를 후위로: 먼저 계산 순서대로 괄호를 치고 (A+(B×C)) → 연산자를 각 괄호 뒤로 보내면 → A B C × + 완성! 컴퓨터는 괄호가 필요 없는 후위 표기를 스택으로 계산해요.
시험 포인트 — "중위 표기 → 후위 표기 변환"이 최다 출제예요. 괄호 치고 → 연산자를 괄호 뒤로, 이 2단계만 기억하세요.
