매뉴얼 작성과 국제 표준 품질 특성

2026-08-27 · 오늘 배울 개념 5개 + 퀴즈 10문제 (약 1시간)

복습 한 스푼 🥄

어제(Day 54)는 패키징과 DRM을 배웠어요. 딱 하나만 다시: DRM에서 클리어링 하우스는 라이선스 발급·정산, 패키저는 암호화 포장, DRM 컨트롤러는 사용 권한 통제를 담당했죠. 오늘은 제품과 함께 전달하는 매뉴얼과, 소프트웨어가 얼마나 좋은지를 재는 국제 표준 품질 특성을 배웁니다.

1. 설치 매뉴얼 — 설치의 모든 과정을 담는다

설치 매뉴얼은 제품을 설치하는 방법을 처음부터 끝까지 안내하는 문서예요. 작성 기준이 시험에 그대로 나옵니다.

작성 기준설명
사용자 기준개발자가 아닌 사용자가 읽는다는 전제로 작성
전 과정 수록설치 시작부터 완료까지 빠짐없이 순서대로 기술
화면 이미지 첨부단계마다 그림(스크린샷)을 넣어 이해를 도움
오류 메시지 포함설치 중 생길 수 있는 오류와 해결 방법까지 안내

설치 매뉴얼의 구성은 다음과 같아요.

구성내용
개요 · 서문문서 이력, 설치 도구·환경·절차 요약, 주의 사항
기본 사항제품의 구성 요소, 최소 실행 환경(하드웨어·운영체제)
설치 절차단계별 설치 방법 (화면 이미지 포함)
설치 후 확인정상적으로 설치됐는지 점검하는 방법
FAQ · 고객 지원자주 묻는 질문과 문의 연락처
시험 포인트 — "설치 매뉴얼은 사용자 기준으로 작성하며, 오류 메시지와 해결 방법까지 포함한다"가 대표 출제 문장입니다.

2. 사용자 매뉴얼 — 어떻게 쓰는지를 담는다

사용자 매뉴얼은 설치가 끝난 뒤 제품의 기능을 어떻게 사용하는지 알려 주는 문서예요. 기능 단위(컴포넌트 단위)로 정리합니다.

항목내용
작성 순서① 기능(컴포넌트) 식별 → ② 사용자 관점의 구성 설계 → ③ 사용 방법 작성 → ④ 검토하고 완성
참고 자료컴포넌트 명세서와 구현 설계서를 바탕으로 기능을 정리
포함 내용기능별 사용법, 화면 설명, 오류 대처법, 자주 묻는 질문, 고객 지원 정보
두 매뉴얼의 차이 — 설치 매뉴얼은 "어떻게 깔까", 사용자 매뉴얼은 "어떻게 쓸까"예요. 가전제품 상자에 들어 있는 "설치 안내서"와 "사용 설명서"의 차이와 같습니다.
시험 포인트 — 사용자 매뉴얼은 컴포넌트(기능) 단위로 작성하며, 근거 자료로 컴포넌트 명세서·구현 설계서를 사용합니다.

3. ISO/IEC 9126 — 품질 특성 6가지

ISO/IEC 9126은 소프트웨어의 품질을 여섯 가지 특성으로 나누어 평가하도록 정한 국제 표준이에요. 2과목의 최다 출제 표준입니다.

품질 특성쉬운 뜻세부 항목
기능성
(Functionality)		요구한 기능을 제대로 제공하는가적합성, 정확성, 상호 운용성, 보안성, 준수성
신뢰성
(Reliability)		오류 없이 꾸준히 동작하는가성숙성, 결함 허용성, 회복성
사용성
(Usability)		사용자가 쉽게 배우고 쓸 수 있는가이해성, 학습성, 운용성
효율성
(Efficiency)		적은 자원으로 빠르게 처리하는가시간 효율성, 자원 효율성
유지 보수성
(Maintainability)		고치기 쉬운가분석성, 변경성, 안정성, 시험성
이식성
(Portability)		다른 환경에 옮겨 써도 잘 되는가적응성, 설치성, 대체성, 공존성
외우는 법 — "기·신·사·효·유·이". 기능이 되고(기), 안 죽고(신), 쓰기 쉽고(사), 빠르고(효), 고치기 쉽고(유), 옮겨도 되면(이) 좋은 소프트웨어예요.
시험 포인트 — "다른 환경으로 옮겨도 사용할 수 있는 정도" → 이식성. "오류 발생 시 스스로 복구하는 능력" → 신뢰성(세부: 회복성). "사용자가 쉽게 배울 수 있는 정도" → 사용성(세부: 학습성). 세부 항목이 어느 특성에 속하는지 묻는 문제가 많습니다.

4. ISO/IEC 25010 — 9126의 개정판(8가지)

ISO/IEC 25010은 ISO/IEC 9126을 개정해 8개 특성으로 늘린 표준이에요. 보안성과 호환성이 독립된 특성으로 올라온 것이 핵심 변화입니다.

8가지 품질 특성
① 기능 적합성 ② 성능 효율성 ③ 호환성 ④ 사용성
⑤ 신뢰성 ⑥ 보안성 ⑦ 유지 보수성 ⑧ 이식성
왜 바뀌었나? — 9126이 만들어진 때보다 지금은 해킹 위협과 기기 간 연동이 훨씬 중요해졌어요. 그래서 기능성의 하위에 숨어 있던 보안성을 독립시키고, 호환성을 새로 넣었습니다.
시험 포인트 — 9126은 6개, 25010은 8개. 25010에서 새로 독립한 두 가지는 보안성과 호환성입니다. 숫자를 바꿔 놓은 보기에 주의하세요.

5. 그 밖의 품질 관련 국제 표준

표준내용
ISO/IEC 12119패키지 소프트웨어(상품으로 판매되는 완성 제품)의 품질 요구사항과 테스트에 관한 표준
ISO/IEC 14598소프트웨어 품질을 평가하는 절차와 기준을 정한 표준. 개발자·구매자·평가자의 관점을 나누어 규정
ISO/IEC 25000
(SQuaRE)		9126과 14598을 통합한 품질 평가 통합 표준. 여러 부분(2501n, 2502n 등)으로 구성되며 25010이 그중 하나
한 줄 정리 — 12119는 "완성 상품의 품질", 14598은 "평가하는 방법", 25000은 "둘을 합친 통합판"입니다.
시험 포인트 — ISO/IEC 25000 = 9126 + 14598 통합이라는 한 줄이 그대로 출제됩니다. 이번 주(Day 50~55) 형상 관리·빌드·패키징이 끝났으니, 내일(Day 56)은 주간 복습 + 종합 테스트 15문제입니다.
