정렬 알고리즘 ② — 퀵·합병·힙

2026-08-13 · 오늘 배울 개념 5개 + 퀴즈 10문제 (약 1시간)

복습 한 스푼 🥄

어제(Day 40)는 O(n²)의 단순 정렬 3형제를 배웠어요. 딱 하나만 다시: 버블은 1회전 후 최댓값이 맨 뒤, 선택은 최솟값이 맨 앞에 확정! 오늘은 훨씬 빠른 O(n log n)급 고급 정렬 3형제를 배웁니다.

1. 분할 정복 — 고급 정렬의 공통 전략

오늘 배울 퀵·합병 정렬의 공통 전략은 분할 정복(Divide and Conquer)이에요. 큰 문제를 작게 쪼개고(분할), 각각 해결한 뒤(정복), 합치는(결합) 방식입니다.

비유 — 두꺼운 문제집 한 권을 혼자 다 풀기 힘드니, 반으로 나눠 친구와 각자 풀고 답을 합치는 것! 쪼갤수록 각 조각은 쉬워져요.
시험 포인트 — "분할 정복 기법을 사용하는 정렬은?" → 퀵 정렬, 합병 정렬. 둘 다 답이 될 수 있게 기억하세요.

2. 퀵 정렬 (Quick Sort) — 기준(피벗)으로 편 가르기

퀵 정렬은 기준 값인 피벗(pivot)을 하나 정해서, 피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 나눈 뒤 각 묶음을 또 같은 방법으로 정렬해요.

비유 — 키 기준 한 명(피벗)을 세우고 "이 친구보다 작으면 왼쪽, 크면 오른쪽!" 하고 편을 가른 다음, 각 편에서 또 기준을 세워 반복하는 거예요.

평균은 O(n log n)으로 매우 빠르지만, 이미 정렬된 데이터에 피벗을 잘못 잡으면 편이 한쪽으로만 쏠려 최악의 경우 O(n²)이 됩니다.

시험 포인트 — 키워드 피벗 = 퀵 정렬. 그리고 "퀵 정렬의 최악 시간 복잡도는 O(n²)"가 함정 문제로 자주 나와요(평균만 알면 틀리기 쉬움).

3. 합병 정렬 (Merge Sort) — 반씩 나눴다 합치며 정렬

합병 정렬은 데이터를 더 나눌 수 없을 때까지 반씩 나눈 뒤, 두 묶음씩 크기 순서를 맞춰 가며 다시 합치는 정렬이에요.

비유 — 카드 더미를 한 장씩 될 때까지 나눈 다음, 두 더미씩 작은 카드부터 차례로 합쳐요. 정렬된 두 더미를 합치는 건 맨 위끼리만 비교하면 되니 쉽죠!

장점: 어떤 데이터가 와도 항상 O(n log n)을 보장(최악도 같음). 단점: 합칠 때 쓸 추가 메모리 공간이 필요해요.

시험 포인트 — 합병 정렬 = 항상 O(n log n) 보장 + 추가 공간 필요. 퀵(최악 O(n²), 추가 공간 거의 불필요)과 대비되는 특징입니다.

4. 힙 정렬 (Heap Sort) — 우승자 뽑기 토너먼트

힙(heap)은 부모가 자식보다 항상 크거나(최대 힙) 작은(최소 힙) 완전 이진 트리예요. 힙 정렬은 데이터를 힙으로 만든 뒤, 루트(최댓값 또는 최솟값)를 하나씩 꺼내며 정렬합니다.

비유 — 토너먼트 대진표! 결승(루트)에는 항상 우승자(최댓값)가 있어요. 우승자를 빼내고 대진표를 다시 정리하면 다음 우승자가 올라오고... 이걸 반복하면 순위표(정렬)가 완성되죠.

시간 복잡도는 최선·평균·최악 모두 O(n log n)이에요.

시험 포인트 — 힙 정렬의 재료는 Day 38에 배운 완전 이진 트리! "완전 이진 트리를 이용하는 정렬은?" → 힙 정렬입니다.

5. 이번 주 마무리 — 정렬 성적표 총정리

정렬평균최악키워드
버블O(n²)O(n²)이웃 교환, 최댓값 뒤로
선택O(n²)O(n²)최솟값 선택, 앞으로
삽입O(n²)O(n²)끼워 넣기, 정렬된 자료에 최적(최선 O(n))

이번 주 정리 — 리스트(배열·연결)→스택·큐→트리→그래프→정렬까지, 자료구조의 큰 그림을 완주했어요! 내일(Day 42)은 이번 주 전체 복습 + 종합 테스트입니다.
시험 포인트 — 이 표에서 최악이 O(n²)인 유일한 O(n log n)급 정렬 = 퀵. 최악까지 O(n log n) 보장 = 합병·힙. 이 구분이 최다 출제!
