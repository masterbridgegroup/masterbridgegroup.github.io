통합 구현과 단위 모듈 — 조각을 하나로 합치기

2026-08-20 · 오늘 배울 개념 5개 + 퀴즈 10문제 (약 1시간)

복습 한 스푼 🥄

어제(Day 47)는 데이터베이스와 DBMS를 배웠어요. 딱 하나만 다시: DBMS의 3대 기능은 정의·조작·제어이고, 스키마 중 개념 스키마는 조직에 딱 하나, 외부 스키마는 사용자마다 여러 개였죠. 오늘은 만들어 놓은 프로그램 조각들을 하나의 시스템으로 합치는 과정을 배웁니다.

1. 단위 모듈이란? — 프로그램의 부품 하나

단위 모듈(Unit Module)은 소프트웨어를 이루는 기능 단위의 최소 부품이에요. 하나의 모듈은 보통 한 가지 일만 합니다.

비유 — 자동차를 만들 때 엔진, 바퀴, 핸들을 각각 따로 만들죠. 이 부품 하나하나가 단위 모듈이고, 부품을 조립해 자동차를 완성하는 일이 통합 구현이에요. "화면에 로그인 창 띄우기", "비밀번호 맞는지 확인하기" 같은 게 각각 하나의 모듈이 됩니다.

모듈은 두 가지로 이루어져 있어요.

구성내용
단위 기능 명세서이 모듈이 무엇을 하는지 적은 설명서 (입력·출력·처리 내용)
입·출력 기능 구현실제로 값을 받아 처리하고 결과를 내보내는 코드
시험 포인트 — 좋은 모듈의 조건은 1과목에서 배운 그것입니다. 결합도는 낮게(약하게), 응집도는 높게(강하게)! 모듈끼리 덜 엉키고, 모듈 하나는 한 가지 일에 집중해야 한다는 뜻이에요. 이 문장은 전 과목에서 반복 출제됩니다.

2. 통합 구현 — 조각을 이어 붙이는 과정

통합 구현은 단위 모듈들과 외부 시스템을 연결해 하나의 완성된 시스템으로 만드는 과정이에요. 구성 요소는 다음과 같습니다.

구성 요소역할
송신 시스템·모듈데이터를 보내는 쪽. 필요한 데이터를 만들어 전송
수신 시스템·모듈데이터를 받는 쪽. 받아서 자기 형식으로 변환·저장
중계 서버둘 사이에서 데이터를 전달·변환해 주는 중간 서버 (필수는 아님)
연계 데이터실제로 주고받는 데이터 (형식·항목을 미리 정의해 둠)
비유 — 쇼핑몰에서 주문을 하면, 쇼핑몰(송신)이 택배사 시스템(수신)에 배송 정보를 넘기죠. 이때 중간에서 형식을 맞춰 주는 서버가 중계 서버이고, 넘기는 주문번호·주소 묶음이 연계 데이터예요.
시험 포인트 — 통합 구현은 송신 → (중계) → 수신의 흐름으로 기억하세요. 중계 서버는 선택 사항이라는 점이 함정으로 나옵니다.

3. IPC — 프로그램끼리 대화하는 방법

IPC(Inter-Process Communication, 프로세스 간 통신)는 따로 돌아가는 프로그램들이 데이터를 주고받는 방법을 모아 부르는 말이에요. 모듈을 합치려면 서로 말을 걸 수 있어야 하니까요.

방식쉬운 설명
공유 메모리
(Shared Memory)		메모리 한 구역을 공동 칠판처럼 함께 쓰며 읽고 씀. 가장 빠름
소켓
(Socket)		네트워크로 연결해 데이터를 주고받음. 다른 컴퓨터와도 통신 가능
메시지 큐
(Message Queue)		메시지를 줄 세워 두고 상대가 꺼내 감. 서로 기다리지 않아도 됨(비동기)
파이프
(Pipe / Named Pipe)		관을 하나 놓고 한쪽에서 넣으면 다른 쪽으로 흘러나옴
원격 프로시저 호출
(RPC)		다른 컴퓨터의 함수를 내 함수처럼 불러서 실행
한 줄로 구분 — 공유 메모리는 공동 칠판, 소켓은 전화선, 메시지 큐는 사서함, 파이프는 수도관, RPC는 남의 집 리모컨 누르기.
시험 포인트 — "메시지가 큐에 저장되어 비동기로 처리되는 IPC 방식은?" → 메시지 큐. "두 프로세스가 같은 메모리 영역을 공유하는 방식은?" → 공유 메모리. 용어와 설명 짝짓기로 출제됩니다.

4. 개발 지원 도구 — 혼자 다 하지 않는다

개발을 도와주는 도구들의 이름과 역할을 정리해 둡시다. 용어만 묻는 문제로 자주 나와요.

도구역할예시
IDE
(통합 개발 환경)		코드 작성·컴파일·디버깅을 한 화면에서 다 할 수 있게 묶은 도구이클립스, 비주얼 스튜디오, IntelliJ
빌드 도구소스 코드를 실행 가능한 형태로 자동 변환하고 필요한 부품(라이브러리)을 챙겨 옴Ant, Maven, Gradle
협업 도구여러 사람이 일정·문서·이슈를 공유Jira, Confluence, Slack
형상 관리 도구소스 코드의 변경 이력을 관리Git, SVN, CVS
테스트 도구코드가 제대로 동작하는지 자동으로 검사JUnit, Selenium
IDE의 5가지 기능 — 개발(Coding) · 컴파일(Compile) · 디버깅(Debugging) · 배포(Deployment) · 형상 관리 연동. "코·컴·디·배"로 묶어 두세요.
시험 포인트 — 빌드 자동화 도구 3형제(Ant · Maven · Gradle)는 다음 주(형상 관리·빌드 자동화)에 다시 나오는 핵심입니다. 이름만이라도 미리 눈에 익혀 두세요.
